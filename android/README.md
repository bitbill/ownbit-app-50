# Ownbit core — Android

This directory is reserved for the Android 5.0 core code that touches private keys
(mnemonic generation, key storage, key derivation and signing). It will be published here
by the Android team.

Android 5.0 uses the same JavaScript signing bundles as iOS — see [`../js`](../js).

---

本目录留给 Android 5.0 中接触私钥的核心代码（助记词生成、密钥保管、密钥派生与签名），将由 Android 团队发布。
Android 5.0 与 iOS 使用同一套 JavaScript 签名库，见 [`../js`](../js)。
