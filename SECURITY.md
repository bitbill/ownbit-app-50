# Security policy

If you believe you have found a security vulnerability in the code in this repository,
please report it privately to **support@ownbit.io** rather than opening a public issue.
Please include enough detail to reproduce the problem. We will acknowledge your report
and keep you informed of the fix.

如果你在本仓库的代码中发现安全漏洞，请发邮件到 **support@ownbit.io** 私下报告，不要公开提 issue。
